# StockMind MVC مع SQL Server

الصفحة الرئيسية تحتفظ بمشهد المستودع ثلاثي الأبعاد وتصميم StockMind الأصلي. صفحات العمليات مبنية كـ Razor Views بحسب مجلدات Controllers وViews. طبقة Entity Framework Core مرتبطة بنسخة SQL Server المستعادة باسم StockMindMVC.

- Controllers تشمل الحساب، السوق، السلة، الطلبات، الملف الشخصي، البائع، الإدارة، وتحليل الشراء.
- Data/StockMindDb.cs يحوي ربط الجداول والعلاقات، وModels/Database يحوي نماذج قاعدة البيانات.
- سكربتات Database تجهز قاعدة SQL Server من النسخة الاحتياطية الخاصة بالمشروع.
- رسوم الصفحة الرئيسية ثلاثية الأبعاد تستخدم نفس المكتبات التي يستخدمها المشروع الأصلي وتتطلب WebGL واتصالاً بمزود المكتبات.
- الدفع عند الاستلام وتحديثات الشحن الداخلية وتأكيد الاشتراكات اليدوي مدمجة. التحليلات تعتمد على قواعد وبيانات SQL Server.
## التشغيل على جهازك

قاعدة `StockMindMVC` مستعادة ومجهزة على SQL Server المحلي. افتح `StockMind.sln` في Visual Studio مع دعم .NET 10، ثم اختر ملف التشغيل `http` وشغّل المشروع. ويمكن تشغيله من PowerShell داخل هذا المجلد عبر:

```powershell
dotnet run --launch-profile http
```

الرابط المحلي هو http://localhost:5090. الاتصال يستخدم Windows Authentication. إعداد الاتصال في `appsettings.json` ويمكن تجاوزه بالمتغير `ConnectionStrings__StockMind`.

## إنشاء الحسابات

المشتري يسجّل من صفحة Create account. لتسجيل بائع، أدخل اسم المتجر في الصفحة نفسها. حساب المدير يُنشأ من الجهاز الذي لديه صلاحية الكتابة في SQL Server. عيّن كلمة مرور خاصة غير موجودة في ملفات المشروع ثم احذف المتغير بعد الأمر:

```powershell
$env:STOCKMIND_PROVISION_PASSWORD = Read-Host 'New admin password (12+ characters)' -MaskInput
dotnet run --no-launch-profile -- provision admin admin@your-domain.example 'StockMind Admin'
Remove-Item Env:STOCKMIND_PROVISION_PASSWORD
```

الأمر ينشئ حساباً جديداً ببريد فريد. حسابات النسخة الأصلية محفوظة في القاعدة وتحتوي قيمة كلمة مرور تجريبية غير متوافقة مع ASP.NET Core PasswordHasher. استخدم التسجيل أو أمر الإنشاء للدخول بحساب جديد.

## نقل قاعدة البيانات

استخدم نسخة SQL Server الاحتياطية المتوفرة لديك محلياً. يمكن استعادته بنفس السكربت التالي بتغيير مسار الملف. أسامي الملفات المنطقية داخل النسختين هي StockMindDB وStockMindDB_log.

لاستعادة النسخة الأصلية في قاعدة جديدة باسم `StockMindMVC`، ضَع ملف النسخة في مجلد يمكن لخدمة SQL Server قراءته، ثم شغّل:

```powershell
.\Database\Restore-StockMind.ps1 -BackupPath 'C:\path\to\StockMindDB.bak'
```

السكربت يجهّز الكتالوج بعد الاستعادة. إذا استعدت القاعدة يدوياً، شغّل `Database/01-prepare-catalog.sql` عليها مرة واحدة. السكربت يتعرف على بيانات الكتالوج بواسطة SKU ويمكن إعادة تشغيله. النسخة الأصلية `StockMindDB` تبقى مستقلة عن التطبيق.

## البيانات والتدفقات

- المتجر يعرض الجداول المستعادة من SQL Server. أضيفت ثلاثة منتجات بصور من الأرشيف، والأسعار من الواجهة المرفقة. الكميات المضافة تجريبية، والنسخة المرفقة تتضمن أيضاً سجلات توضيحية.
- المشتري يسجّل الدخول قبل إضافة عناصر للسلة. السلة والمفضلة والطلبات محفوظة بحسابه في SQL Server. تسجّل عملية الشراء سعر البيع، وتخصم المخزون، وتنشئ طلباً وشحنة لكل بائع وسجل الدفع عند الاستلام في معاملة واحدة.
- المدير يعتمد المتجر، ثم يعتمد منتجاته. المدير يحدث الشحن ويسجل استلام المبلغ. تُنسّق عمليات المخزون والمراجعة بمعاملات SQL Server.
- الاشتراكات تسجل طلب دفع يدوي وتأكيده إداريّاً. مؤشرات المخزون تعتمد على الكميات ومبيعات آخر 28 يوماً.
- بيانات التطبيق لا تستخدم ASP.NET Session أو sessionStorage أو localStorage. كوكي المصادقة تحمل معرّف الحساب وعلامة لإبطال الدخول عند تغيير كلمة المرور. الدور وحالة الحساب يقرآن من Users وRoles عند كل طلب، والإشعارات محفوظة في القاعدة.

## تحديث نسخة موجودة

على هذا الجهاز تم تجهيز جدول التسجيل الجديد مسبقاً. إذا فتحت المشروع على قاعدة سبق استعادتها على جهاز آخر، نفذ `02-registration-profiles.sql` من مجلد Database على قاعدة StockMindMVC. سكربت الاستعادة ينفذه تلقائياً للنسخ الجديدة. يحفظ التسجيل رقم الهاتف، واسم المستخدم، وعنوان التوصيل، والصورة الاختيارية في SQL Server.

## تفعيل تسجيل الدخول لحساب موجود في النسخة الأصلية

إذا كان الحساب مستورداً بكلمة مرور تجريبية غير متوافقة، غيّرها محلياً بإذن صاحب الحساب. هذا الأمر يحتفظ بالدور الموجود في SQL Server ويُبطل كوكي الدخول القديمة. استبدل البريد بالموجود في جدول Users.

```powershell
$env:STOCKMIND_PROVISION_PASSWORD = Read-Host 'New password (12+ characters)' -MaskInput
dotnet run --no-launch-profile -- reset-password 'existing-account@example.com'
Remove-Item Env:STOCKMIND_PROVISION_PASSWORD
```

تسجيل الدخول يوجّه المدير إلى الإدارة، والبائع إلى مركز البائع، والمشتري إلى السوق. تغيير دور الحساب في SQL Server يظهر في الصلاحيات عند الطلب التالي.
